## 1. 核心决议

1. 每个玩家在**大厅独立选两把不同 I 级武器**，准备后锁定到本局结束；再次开局前可重新选择。开局两把武器都可自动攻击。
2. 六种规划武器：火焰弹 `fireball`、冰晶碎片 `ice_shards`、静电链 `chain_lightning`、穿透箭 `piercing_arrow`、守护法环 `guardian_ring`、虚空法球 `void_orb`。旧回旋刃只用于历史/兼容，不作为 V2 正式武器。
3. 每把武器的 I 级有独立价值；升级到 II 级从两条**互斥分支**选择其一；III 级加强已选分支，不能改选。
4. **个人双重祝福**必须拥有指定的两把武器和双方 II 级分支，再消耗一次升级选择获取；至多一项主要双重祝福，不占武器或被动槽。队友的武器不能替你满足解锁前置。
5. **基础跨玩家交互**不受个人祝福限制：合法的火种、冰晶、节点、空间区域等可以被队友的技能使用；强化效果取决于触发者自己的祝福。
6. 为防止“随机到没用的分支”，大厅每种武器对均展示可用的高级联动与对应两条前置分支；升级候选按已选武器和规划路径加权，合法双重祝福满足条件后下一次升级保底出现。
7. 4 分钟原型与 12 分钟正式模式使用**不同经验节奏配置**，但共享武器/分支/共振规则。

## 2. 六武器 / 十二分支名录

| 武器 | 分支 A | 分支 B | 武器职责 |
|---|---|---|---|
| 火焰弹 | 裂变火球 `split`（即时派生火星） | 余烬火种 `ember`（**单独持续灼烧**） | 即时爆发 / 固定火场持续输出 |
| 冰晶碎片 | 霜爆晶簇 `crystal` | 寒霜领域 `frostfield` | 冰晶/减速 |
| 静电链 | 无尽电弧 `arc` | 蓄能雷核 `capacitor` | 传导/储能 |
| 穿透箭 | 千羽贯穿 `volley` | 猎杀钉桩 `pylon` | 穿透/锚点 |
| 守护法环 | 刃环风暴 `blade_storm` | 折射法环 `refraction` | 跟随玩家的近身领域/折射 |
| 虚空法球 | 坍缩奇点 `collapse` | 空间锚点 `anchor` | 固定远程聚怪/空间改向 |

武器 A 与 B 无数值强弱预设，分支必须有独立收益，不能只有满足双重祝福时才有效。特别是：**没有坍缩奇点和任何祝福时，`fireball.ember` 也应每 15 Tick 对范围内敌人造成一次独立灼烧**，具体初值与同敌人限流见 V2.6；V2 火球 III 不可无条件继承旧版通用爆炸。

**设计约束：** 每一组合需在开局界面给出“玩法关键词 + 前置分支 + 可视预览”；双重祝福为**高级奖励**，基础技能依然能自主输出。跨玩家对象来源可共享，但任何对象每次只可消费一次。所有额外弹体及传播层数有硬上限，反应生成的次生伤害默认不得再次生成同类反应。

## 4. 额外可选择内容（不虚增武器槽）

### 4.1 通用被动与中性祝福（设计池）

沿用三被动槽、II 级上限。正式开放前扩充到 **12 种**：
- 狂怒之心：基础伤害；迅捷施法：冷却；坚韧体魄：生命。
- 聚能回响：小幅共振充能效率；裂隙学识：领域持续时间；危机感知：冲刺冷却。
- 破甲专精：对高护甲目标有效伤害；猎群本能：靠近多个敌人时范围效率；灵巧步法：移动速度。
- 不灭余烬：状态持续时间；远视瞄准：远程攻击距离；守护协奏：队友附近获得小幅防护。

避免隐藏的无条件连乘；所有百分比与上限都由数据表配置并经平衡验证。

### 4.2 精进祝福（正式模式）

III 级后的可选“小精进”不增加武器槽：分裂上限、区域范围、穿透次数等只补足已有玩法，不产生无限传播。后期最多 1 次传奇强化，待 12 分钟原型再定。

### 4.3 多人配合

同武器组合的队友允许走不同分支；两个玩家可以共同提供火种、晶簇、节点等。个人高级祝福**只能由本人装备的分支解锁**；反应结算归属施放者/对象提供者分别记录，合作贡献显示在结算里。

## 5. 大厅选择体验与错误处理

- 每人从正式已上线、可用的六武器名单中**恰选两把不同武器**；初始界面给推荐组合，不强制推荐。首次研发阶段只开放已实现的火焰弹+虚空法球，剩余显示“开发中”而不能误选。
- 选择由客户端发 `loadout.select` 的稳定 ID 列表；服务端只在 `LOBBY` 接收，校验合法、不同、仅已上线、玩家本人。准备后不可修改；如需修改先取消准备。全部队员有合法选择并准备才开始。
- 离线与重新开局：保留上一局的大厅选择用于重新准备，但每一局的等级、分支、祝福、火种、投射物重置。
- UI 展示当前两武器、可用祝福名、需要的 II 级分支和“开发中”状态；对非法/过期/重复请求拒绝且不得修改状态。

## 6. 升级流程（开局两把武器后）

- 取消战斗过程中的“解锁第二武器”；升级只出现当前两武器的 II 级分支、III 级强化、通用被动、合法双重祝福。
- 升级 1、2：至少提供对应尚未定分支武器的分支候选，以保证能在前期明确路线；分支选定后不会被另一条覆盖。
- **升级只能手动选择**：不设置升级倒计时，不会在等待过久时自动选第一张卡。所有仍在房间内且有合法候选的玩家提交选择后，下一 Tick 统一恢复战斗；断线玩家不阻塞，重抽不等于确认。
- 双重祝福前置：**同一玩家拥有两条指定 II 级分支**，祝福尚未拥有且主祝福槽为空；满足条件后下一次升级保底候选（最多三个选项）。
- 4 分钟：建议首次升级在 30～45 秒、第二次在 65～90 秒、第三次在 110～150 秒出现。体验目标为 2 分钟左右开始融合；精确经验阈值需实测。
- 12 分钟正式玩法：保留较长的成长与 Boss 时间窗。升级暂停时，战斗计时和所有领域剩余寿命必须同时暂停。
- 维护独立确定性升级 RNG，并使用稳定候选 ID。选择/重抽要保持服务端合法性和多人同步。

## 7. 技术路线 / 决定顺序

| 阶段 | 交付物 | 通过标准 |
|---|---|---|
| **D0** | 独立 V2 分支 + 设计基线；老回旋刃保留 | 旧测试无回归 |
| **D1** | 两武器大厅选择、合法性校验、状态同步、准备锁定 | 单/双人可预选并锁定；违规选项被拒 |
| **D2** | 变体升级基础设施、II/III、祝福前置条件、池过滤与保底 | 确定性、互斥、合法，旧模式可回退 |
| **D3** | 火焰弹 + 虚空法球 I 级技能、引力场、视觉 | 两武器自动攻击、不同敌群目标、可靠结算 |
| **D4** | 余烬火种 + 坍缩奇点 + 坍缩爆炎；**V2.6 补完独立灼烧与消耗补偿** | 单/双人可正常融合，且无祝福时火种仍独立输出；同目标全队火场伤害限流、跨玩家消费唯一 |
| **D5** | 补齐裂变火球 `split` II/III、核对已有空间锚点 `anchor` II/III，取消 V2 通用 III 爆炸 | 火焰两分支各自独立收益；空间锚点无其他可改向弹体仍有效；预览与 UI 一致 |
| **D6** | 穿透箭 + 静电链 + 雷霆矩阵 | 第二种玩法与第一种清晰不同 |
| **D7** | 其余两武器和 15/15 祝福的实现与平衡 | 所有配对存在可触发高级联动 |
| **D8** | 12 分钟正式模式、完整敌人/Boss、重连/压测/音画 | 开放前综合验收 |

**实施策略：** 先在独立分支完成 D0～D4 再评估；每个里程碑单独提交，运行 `npm run typecheck`、`npm run build`、`npm test`、`npm run test:integration`，新增回归用例。不得把尚未实现的六把武器放进可选择的正式列表，避免无效选择。

## 8. 验收门槛

1. 两人互不影响地选择双武器，服务器确保只用合法 ID，单局战斗中不可修改。
2. 单武器与分支不依赖高级祝福即可清怪；任意 15 配对最终都存在高级组合路线。
3. 完整「火种生成→奇点吸收→强力坍缩」由服务端计算，只广播必要视觉事件，重复消息不造成重复伤害。
4. 伤害、状态、生效时间与对象消费确定性可回归，同一随机种子与输入行为一致。
5. 旧版回旋刃代码保留直到 V2 双武器机制稳定，并清晰标记历史兼容路径。
6. 大量杂兵与多人同屏时避免无限粒子、无限嵌套连锁、无上限状态堆积。
