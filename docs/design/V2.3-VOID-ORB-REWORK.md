# 《异界共振》V2.3 虚空法球重做：吞噬核心

> **2026-10-11 现行规则覆盖说明：** [V2.6 余烬火种独立灼烧与坍缩爆炎](./V2.6-FIREBALL-EMBER-STANDALONE.md) 已锁定余烬火种 II/III 的独立伤害、重叠限流、火种剩余能量转换方案；[V2.6 全局设计评审](./V2.6-WEAPON-BOON-DESIGN-AUDIT.md) 列出其余设计风险和当前代码欠账。**本页原型旧参数仍保留供追溯，但不覆盖上述现行设计。相关功能尚未实现。**

**状态：** V2 独立开发分支中的原型实现；视觉与数值待浏览器实机调优  
**依据：** [V2.2 六武器与 15 组合规划](./V2.2-ALL-15-DUAL-WEAPON-BUILD-PLAN.md)

## 1. 改造目标与问题

旧版虚空法球在敌群位置立刻出现一块紫色范围，20 Hz 逻辑下每 Tick 牵引约 2.5 单位，最后触发一次普通范围伤害；视觉主要是不断淡出的圆圈。它没有明显的武器发射、吞噬积累与坍缩反馈。

V2.3 将武器身份明确为**投射 → 吞噬 → 坍缩**：必须看到一枚从玩家出发的真实投射物、能明显与怪物移动抗衡的引力、死亡残响向核心汇入，最后先收缩后冲击。空间锚点是同一把武器的互斥辅助分支，而不是第二种常驻高伤害黑洞。

## 2. I 级：虚空吞噬之核

| 行为/参数 | V2.3 原型规则 |
|---|---|
| 施放间隔 | 38 Tick = 1.90s（可由迅捷施法被动降低） |
| 飞行实体 | 从玩家坐标发射的 `weapon.void_orb` 服务端投射物 |
| 飞行速度 | 520 世界单位/s；固定朝发射时选定的位置，不追踪死亡敌人 |
| 飞行命中 | 路径掠过敌人时有限伤害，每个敌人本次飞行最多命中一次 |
| 目标选择 | 420 单位内的候选敌人位置，优先附近最密集的群组，ID 保证平局确定性 |
| 成型核心 | 飞行到达目标点后才生成；半径 104 |
| 引力 | 22 Tick = 1.10s，每 Tick 按距核心远近以约 4.3～6.2 单位推向核心，带少量切向旋转 |
| 牵引对象 | 每 Tick 最多 10 个普通追击怪；充能/冲锋锁定行为不被虚空位移中断 |
| 死亡残响 | 核心范围内、核心创建后死亡的敌人贡献充能；单次死亡至多被一个核心获取 |
| 充能上限 | 普通核心最多 2 层，坍缩奇点分支最多 4 层，每层最终爆发 +5 伤害 |
| 坍缩阶段 | 额外 4 Tick = 0.20s 的收缩阶段，随后一次伤害判定和向外冲击视觉 |
| 坍缩基础伤害 | 22，受到普通武器等级和伤害被动调整 |
| 同时存在 | 每名玩家最多两枚（飞行与核心计入同一限制） |

不直接传送怪物，不对 Boss 强制位移；精英后续增加强度系数时应专门测试。对象存活与冷却遵守服务端 Tick，视觉不得自行决定伤害。

## 3. 两条互斥分支

### A：坍缩奇点（II 级）
- 牵引强度再提高 20%，允许积累最多 4 层死亡残响（基础为 2）。
- 命中火种的「坍缩爆炎」由双重祝福激活，**不是免费获得**。
- III 级：引力半径增加 12；第一次坍缩后延迟 3 Tick 触发一次附加空间冲击，伤害约为基础虚空伤害的 35%，伤害动作有独立 ID。

### B：空间锚点（II 级）
- 法球正常飞行，但抵达后转化为持续约 1.6 秒的固定空间锚点。
- 环绕小幅引力（每 Tick 约 2.2 单位，最多 4 只普通追击怪）和结束时弱化伤害（约基础的 40%）。
- 最多对经过范围的 5 枚友方火焰弹各做一次新的目标选择，真实改变其后续弹道；目标必须是锚点附近未被这发弹体锁定的活敌人。
- III 级：有效半径增加，单次最多处理 8 枚弹体；被改向的火球会沿锚点环绕 4 Tick 后再射向新目标。镜像/再次触发同一类改向仍被禁止。
- 该分支不产生「坍缩爆炎」的前置条件，未来与千羽贯穿及折射法环另有高级组合。

### 两分支定位

| 项目 | 坍缩奇点 | 空间锚点 |
|---|---|---|
| 攻击重点 | 强聚怪、死亡残响、二段坍缩 | 小范围持续控制、弹体改向 |
| 战场位置 | 远处固定核心 | 远处固定锚点 |
| 战斗输出 | 群体爆发 | 引导友方弹体、弱化终结冲击 |
| 可见反馈 | 紫黑吸入 → 聚能发亮 → 核心缩小 → 大型冲击 | 稳定空间纹路 → 火球绕行 → 改向释放 |
| 独立价值 | 无火种也有死亡残响充能 | 无火球可交互时仍有弱牵引与结束伤害 |

## 4. 和火焰弹的「坍缩爆炎」（V2.3 历史数值，V2.6 已覆盖）

- 玩家必须本人持有：**余烬火种（火焰弹 II）+ 坍缩奇点（虚空 II）+ 坍缩爆炎祝福**。
- **V2.3 历史实现规则：** 符合条件的虚空核心在活跃阶段吸收范围内的火种，最多 3 枚，每枚固定增加 16 点最终伤害；被吸收后火种服务器对象立即移除。**该固定 +16 将在实施 V2.6 时改为按剩余脉冲潜力换算的有上限奖励；没有祝福的黑洞不能消费独立灼烧火种。**
- **允许消耗队友制造的火种**，但队友的分支不满足本人解锁前置。
- 火种、残响可以同时为最终坍缩提供有限的伤害强化，但不能再次凭坍缩生成相同的火种或重复制造次级连锁。

## 5. 表现与同步设计

服务器负责 `CombatProjectile` 的实体飞行、`CombatVoidField` 的阶段、引力位移、死亡残响唯一归属、火种消费、改向和最终伤害。

网络以 10Hz 同步真实投射物位置、核心当前位置/阶段/充能、剩余火种列表，并发送带唯一 ID 的主要事件：

- `weapon.void_launched`：投射出手。
- `weapon.void_spawned`：实体抵达并形成核心。
- `weapon.void_essence`：死亡残响被核心吸收。
- `weapon.ember_absorbed`：火种被共振吞噬。
- `weapon.void_collapse_started`：进入短暂收缩阶段。
- `weapon.void_pulse` / `boon.collapse_inferno`：普通/火焰终结坍缩。
- `weapon.void_aftershock`：III 级二段冲击。
- `weapon.void_redirect`：空间锚点改变弹体目标。

客户端第一版使用**多层旋转弧光、中心暗核与吸入粒子**替代实心淡出圆圈；发射、吞噬、充能、收缩与爆发可分辨。美术仍是程序化原型，并非完成的暗黑奇幻特效包。

核心与火种的视觉依赖**同步的持久对象**，而不是客户端倒计时；升级手动选择期间暂停战斗，特效状态不会先于真实结算消失。

## 6. 验收与后续

自动化回归至少覆盖：发射后才成核、沿途命中唯一、强引力但无瞬间传送、冲锋状态不破坏、死亡残响仅归一核心、跨玩家火种消耗唯一、手动升级暂停保留领域、空间锚点限制改向次数、III 级二段冲击有单独伤害事件和上限、旧规则集不回归。

浏览器实机验收仍需观察：怪群能否真正聚集、法球弹道是否清晰、爆燃是否有足够的爆发层次、四人连续施法是否遮挡冲锋危险提示、长时间多人测试的 CPU/带宽与帧率。未通过试玩之前，数值均为建议测试参数。

**本次只重做虚空法球及现有火种高级联动；全部 15 种双重祝福的长期规划保持不变。**
