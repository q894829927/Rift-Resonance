# 《异界共振》V2.5：火焰弹弹道完整重构

**状态：** `codex/v2-dual-weapon-foundation` 实现已提交，仍需浏览器真实手感验收。  
**范围：** V2 火球投射、目标响应、命中、空间锚点和客户端同步；旧版 `legacy` 保留原运行路径。  
**前置：** [V2.4 火球火种优化](./V2.4-FIREBALL-EMBER-READABILITY.md)。

## 1. 根因

旧方案有两套不一致的运动含义：

1. 服务端 `DamageSystem.advanceV2Fireball()` 每 50ms 向移动目标计算转向，限角加上围绕原始方向的全局约束；碰撞通过线段圆检测，但撞击位置仍被写成敌人中心，存在“飞到敌人中心才命中”的瞬移观感。
2. 客户端每帧对 **10Hz 最新位置**做 `100ms` 插值，并用「当前显示位置之差」计算火球尾焰朝向。遇到目标转向、锚点重定向、快照变化和时间差时，“显示朝向”并非服务器运动方向；修正出现反向位移时，火焰尾部直接转到错误侧。
3. 空间锚点的绕行判断曾排在普通 V2 火球分支之后，部分真实 V2 火球根本无法进入绕行路径，导致特效和规则不一致。

## 2. 重构结构

| 模块 | 职责 |
|---|---|
| `simulation/combat/fireballTrajectory.ts` | 纯函数航向积分与最早线段-圆接触时刻，不依赖 Phaser、Colyseus 或全局时钟 |
| `simulation/combat/weapon.ts` | 初始锁定目标和生成飞行状态；旧版维持历史路径 |
| `simulation/combat/damage.ts` | 读取飞行状态、固定 Tick 前进、命中只结算一次、命中后生成火种；锚点的绕行优先于普通航行 |
| `server/LobbyState + lobbyProjection` | 同步权威位置、单位方向向量和速度；不发送客户端碰撞结果 |
| `client/art/v2FireballPresentation.ts` | 10Hz→60FPS 的有上限前向预测；网络包乱间隔时不反向回拉火球 |
| `client/main.ts` | V2 用服务器方向旋转火焰模型；不再用插值位置差估算朝向 |
| `tests/v2-fireball-trajectory.test.mjs` | 纯航向、包抖动、最早命中与重定向回归 |

## 3. 当前明确的运动规则

- 火球速度保持 `360 世界单位/s`，20Hz 固定步长每 Tick 基础路程约 18 单位。
- 发射时记录**初始方向、当前方向、剩余生存 Tick**；单次最多 `32 Tick=1.6s`，命中/出界/超时销毁。
- 追踪每 Tick 最大偏转 `π/16 = 11.25°`。在目标处于飞行方向前方时才纠偏，目标跑到火球背后时不得掉头追逐。
- 普通航向始终限制在初始发射方向左右 `72°` 内，避免左右摇摆后 U 形折返；目标死亡后按当前航向继续飞行，并能撞击沿途其他敌人。
- 每 Tick 计算飞行线段和敌人碰撞圆的**最早交点**，以最早接触时间、再以稳定 ID 排序；只处理最早命中的敌人。爆炸与火种在真实接触位置生成，避免将火球可视位置跃迁到敌人中心。
- 空间锚点的重定向是**显式特例**：将原始方向和当前方向同时改为新目标；III 级绕行需要先完成短暂轨道运动、再进入普通航行。每发子弹仅接受一次重定向。
- 火焰弹的基础攻击间隔、伤害、火种 `5 秒`、每人最多 `8 枚` 均保持 V2.4 策划，不借弹道重构调整构筑强度。

## 4. 客户端显示规则

- 服务端投影同步火球当前位置、`directionX/Y` 和速度。
- 客户端仅针对 V2 火球使用独立表现轨道：按当前权威方向最多**前向预测 80ms**，禁止长网络延迟造成的无限漂移。
- 重复收到相同快照不重启表现轨道；普通小幅修正不得把画面火球沿新前进方向向后拉动。
- 跨大距离或角度剧变（空间锚点特例）允许按权威坐标重新锚定。
- 火焰模型的尾巴按服务端 `directionX/Y` 朝向，不再从视觉位置修正速度推断；客户端不执行碰撞、追踪决策或伤害。

## 5. 验收

**自动化：** 类型检查、构建、原有旧规则单元测试、V2 轨迹测试、多人和 Colyseus 网络烟测。

**人工：** 在浏览器里观察移动玩家、急转弯敌人、目标死亡、跨玩家共振、空间锚点 II/III 改向、慢网络/网络抖动；确认子弹可见朝向与运动一致，不向后拉，不穿过敌人并无故在敌人中心闪现。

**风险：** 受前向约束的火球可能错失跑到身后的目标，这是有意的权衡；它仍会沿途命中其他目标。若命中率偏低，应先调整范围/选靶策略，而不是恢复无条件掉头。
