# V2 菜单与真实地图扩容实施说明（v0.2）

## 本轮已改动

- 按已确认的暗黑奇幻 UI 参考，替换右侧永久显示的集结面板：初始页面仅保留游戏名、地图舞台与「单人游戏 / 多人游戏」两个入口，版本移到右上角；不再堆砌介绍文字。
- 多人游戏：在舞台上弹出居中房间界面；昵称、创建或加入房间、邀请码、成员、确认双武器、准备都在弹层中完成；退出可回到主菜单；进入战斗后，房间弹层消失而战斗 HUD 继续存在。
- 单人游戏：使用与多人相同的 Colyseus 权威房间，不实现第二套本地战斗；自动建房→收到玩家状态→提交 V2 火焰弹/虚空法球→确认后发送准备→服务端开始战斗。单人失败、掉线返回菜单；对局结束后可按现有流程重开。
- 视觉：保持 Phaser 像素世界、现有免费资源和特效实现；CSS 负责画面布局与菜单表现。参考图不是可直接交互的资源贴图，不能将含按钮文字的整张图片作为游戏画布。
- 地图：逻辑范围从 **960×540 → 1440×810**，面积扩大 2.25 倍；服务器移动边界、角色出生点、敌人生成位置、背景装饰和客户端投影读取共享常量，不是只放大 CSS 或摄像机。中心场景不再有被右侧栏挤占的空间。

## 验收要点

1. 首屏只有标题、两个入口；没有固定在右侧的集结栏；960～1920 宽度下主场景无水平溢出。
2. 单人点击后能够进入真正 RUNNING，不需要手工输入房间、选武器或准备；技能命中、升级、重开流程由原服务端执行。
3. 多人点击后可以返回主菜单、创建房间、复制邀请码、第二台浏览器加入、独立双武器选择、手工准备；对局中不再显示房间控制弹层。
4. 缩放浏览器窗口时模型和昵称仍对齐，移动边界覆盖到扩容后的地图区域；单人/双人均检查敌人从四周生成。
5. 检查 V2 手动升级面板、结算与重开、离开房间，确保所有按钮在地图覆盖层上能够点击。
6. GitHub CI 通过后在 ECS 验证 0.2.0.0 版本、首页两入口和真实双人联机；目前无权直接读取 ECS 的 systemd 日志，云端部署与浏览器操作仍需人工验收。

## 已知注意事项

- 扩容后地图面积增加，而 4 分钟原型的刷怪间隔和上限仍保持原数值。因此怪物密度和赶路体验可能与旧地图不同，需要真实试玩后再决定调整刷新密度与目标搜索范围；不要把这次 UI 迭代当作已经完成数值平衡。
- 触发 ECS 新版本发布会重启 Colyseus，原房间连接会中断，不支持房间热迁移。
- 本次未部署含文案的 AI UI 概念图：该图作为美术/布局参考保留在聊天上下文，实际页面以已有可商用资产、Phaser 和 CSS 实现。
