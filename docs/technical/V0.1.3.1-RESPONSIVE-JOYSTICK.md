# v0.1.3.1 响应式布局与虚拟摇杆

## 目标
- 统一舞台和 UI 缩放，以可用 VisualViewport 的宽度、高度确定 `--stage-width`、`--stage-height` 和 `--ui-scale`。
- 桌面/平板横屏展示完整 16:9 地图；手机竖屏的菜单改为竖向布局，战斗地图仍使用 contain 完整显示。
- 显示面积过小、浏览器放大或手机键盘弹出时，优先保留可读文本与可点击按钮，必要时滚动而非无限缩小。
- 手机摇杆拖动输入 `[-1,0,1]` 每轴八方向，原 Colyseus 权威模拟协议不变。真正模拟速度需另立协议版本和服务端验证项目。
- 游戏 RUNNING 且检测到粗指针时显示摇杆与独立冲刺，升级/结算时隐藏并解除输入。
- 房间创建/加入、单人武器选择、升级选择、重开流程不改变语义。

## 浏览器验收
测试 320×568、390×844、667×375、844×390、1024×768、1366×768、1920×1080、2560×1080，关注不溢出、不重叠、标题按钮可读、菜单可点击。手机按住摇杆移动/对角移动/双指冲刺，松开、失焦、升级暂停后角色停止。房间邀请码复制、两人联机、单人开局、多人升级需重测。当前逻辑地图统一 1440×810，不改变碰撞和服务器权威判定。自动 CI 不等于真实设备视觉验收。
