# v0.1.3.4 玩家昵称头顶定位恢复

## 事故与历史

- 原 M2-UI-C（2026-10-10）通过 `playerNameWorldPoint(x,y)` 使用 `PLAYER_NAME_OFFSET_Y=-64`，把昵称放在玩家头顶、生命条上方。
- 2026-10-11 的多轮响应式 CSS 改造后，昵称画在 DOM 覆盖层，坐标仍按 Phaser 内部分辨率写入像素，可能与实际 CSS 绘制的画布尺寸不同，表现为名字偏右和偏下。
- 本次只恢复显示坐标一致性，原昵称偏移、文字大小与配色不变。

## 修复

客户端先用原有 `projectWorldToViewport` 得到 Phaser 内部画布坐标，再借助 `getBoundingClientRect` 和 DOM 覆盖层 `clientWidth/clientHeight` 转到可见 CSS 位置，考虑画布 CSS 压缩、偏移与祖先缩放。最后仅在画面边缘按标签实际尺寸裁切，避免昵称被完全截掉。

不会修改角色世界坐标、碰撞、网络协议、队友昵称规则、生命条、黑洞或其它特效。

## 验收

- 1920×1080、1366×768、800×450 和 320×568 下，玩家昵称始终水平居中于角色头顶，位于 HP 条上方；移动时稳定跟随。
- 改变浏览器缩放或旋转手机之后，昵称不偏向右下。
- 观察队友昵称和重连后再次生成的昵称；贴屏幕边缘时只发生必要的边界限位。
- CI 自动几何测试通过后，仍需在真实网页和手机上检查像素级位置。
