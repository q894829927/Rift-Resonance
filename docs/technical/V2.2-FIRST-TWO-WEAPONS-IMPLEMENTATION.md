# 《异界共振》V2.2 双武器第一阶段实施记录

> 分支：`codex/v2-dual-weapon-foundation`
> 状态：**第一套玩法切片已写入代码，仍须通过 CI 和浏览器实机验收**。
> 前置：[完整 15 组计划](../design/V2.2-ALL-15-DUAL-WEAPON-BUILD-PLAN.md)。

## 本轮实现

- 保留旧版 `createCombatWorld()` 默认规则集，增加 `createCombatWorld("dual_v2")`，避免已完成的回旋刃回归测试失效。
- 服务端通过 `RIFT_V2_DUAL_WEAPONS=1` 启用 V2 模式；大厅需要玩家确认两把不同武器，服务端校验 ID、重复、准备锁定和战斗期篡改。
- **目前允许确认的仅有火焰弹与虚空法球**，界面其余 4 种规划武器明确标示开发中，不假装可玩。
- 火焰弹保持原本追踪射击；取得余烬火种 II 级分支后命中留下可消费的火种，最多 5 枚。
- 新虚空法球自动在可攻击范围内选择最密集的敌群，创建持续 28 Tick 的半径 85 引力场，每 Tick 最多牵引 10 只普通追击怪；结束后由服务端统一结算一次坍缩伤害。
- V2 升级模式只给已装备武器的分支/等级、被动和合法双重祝福，不再提供战斗中解锁回旋刃。
- 玩家拥有 `余烬火种 + 坍缩奇点` 后，解锁「坍缩爆炎」升级候选；吸收最多 3 枚火种，每枚附加 18 点有限伤害，超时释放一次爆燃。所有计算由服务端处理并带有唯一伤害 action ID。
- 客户端增加大厅双武器选择、武器状态与祝福卡片显示、引力场/火种/坍缩爆炎的初版程序化视觉。
- 新增 V2 规则与战斗单元测试；V2 CI 在独立分支运行，同时保留旧版测试。

## 本轮没有实现的内容

- 正式全部六把可选武器及另外十四种双重祝福。
- 裂变火球、空间锚点及 II 级互斥分支二选一（当前只开放「余烬火种」「坍缩奇点」，避免未实现的选项进入对局）。
- 三种职业、全套被动、12 分钟正式模式及 Boss。
- 完整的 VFX、美术、音频和多端浏览器性能验收。

## 本地启用与检查（PowerShell）

服务端终端：

```powershell
$env:RIFT_V2_DUAL_WEAPONS = "1"
npm run dev:server
```

客户端另开终端：

```powershell
npm run dev:client
```

进入游戏，创建房间，点击「确认双武器」，然后「准备并开始」；战斗中分别选择火种与奇点分支，下一次升级应出现「坍缩爆炎」。双人可分别测试独立确认/准备与多人火种来源。

不设置环境变量，服务端使用旧版 `legacy` 模式。两种模式在服务器启动时选择，不能在同一房间中途切换。
