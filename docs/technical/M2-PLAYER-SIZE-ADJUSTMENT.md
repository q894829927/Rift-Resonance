# 玩家尺寸与碰撞半径微调（M2-UI-C 后续）

基线：`b981e5a`（M2-UI-C）。  
范围：玩家显示比例、玩家服务器权威碰撞半径、UI 锚点及冲锋碰撞提示。

## 调整前后

| 项目 | 修改前 | 修改后 |
|---|---:|---:|
| 玩家 Dark World 32×32 精灵缩放 | 3× | **2×** |
| 玩家贴图完整帧显示尺寸 | 96×96 | **64×64** 世界单位 |
| 玩家实际碰撞半径 `PLAYER_COLLISION_RADIUS` | 22 | **16** 世界单位 |
| 玩家实际碰撞直径 | 44 | **32** 世界单位 |
| 狂暴兽冲锋预警半宽 | 46 | **40**（狂暴兽半径 24 + 玩家半径 16） |
| 玩家名牌世界 Y 偏移 | -83 | **-64** |
| 玩家血条世界 Y 偏移 | -58 | **-44** |
| 玩家血条宽度 | 56 | **44** |

玩家体积变小，但未修改怪物体积、人物速度、技能射程、伤害、掉落、经验及战场逻辑尺寸。

## 权威性与兼容性

- `packages/shared/src/movement.ts` 中的共享 `PLAYER_COLLISION_RADIUS` 从 22 改成 16。
- 服务端 `EnemySystem` 的接触伤害与冲锋命中检测直接引用该常量；客户端预测和大厅移动边界也使用相同值，无需重复配置。
- `apps/client/src/art/m2PixelPresentation.ts` 设置渲染规模 2×，保持最近邻像素采样，不采用造成像素边缘不均匀的 2.5×。
- `apps/client/src/art/m1Visuals.ts` 相应收紧玩家脚下圈、影子、身体和生命条。
- `apps/client/src/art/m2CombatReadability.ts` 将危险走廊半宽定义为 `24 + PLAYER_COLLISION_RADIUS`，在后续再次调整人物碰撞半径时自动同步。
- 仅已存在于分支中的同版本客户端和服务端应参与联机。由于移动边界/命中范围发生了真实规则变更，**更新后必须重启服务端并让所有客户端同步版本**。

## 自动验证与浏览器复核

- 新增 `tests/player-hitbox.test.mjs`：校验实际接触距离 18+16=34（普通怪）与 24+16=40（狂暴兽），以及人物移动/冲刺的地图边界。
- 现有 `tests/ui-pixel.test.mjs` 固定精灵缩放 2×，`tests/ui-readability.test.mjs` 校验冲锋提示尺寸。
- GitHub Actions 执行 `npm run verify`、UI 静态检查及 `npm run test:integration`。
- 仍需浏览器实测狭窄怪群中的擦边命中是否符合手感，特别是冲刺期间与狂暴兽的接触判定。这里的主观体验无法由单元测试替代。

后续若还感觉角色太大，建议优先调整正式素材的人物实体占帧比例；不要直接压缩 960×540 世界或任意削减怪物碰撞半径。
