# M2-B 回旋刃：投掷、旋转与折返机制修订

**分支：** `codex/m1-art-cc0-bootstrap`  
**设计依据：** 用户明确要求回旋刃应像飞去来器一样“丢出去，再回旋回来”，优先于此前 GDD 中的“扇形近战”描述。已同步修订 `docs/GDD.md` 的基础武器机制和 III 级成长表。

## 行为规范

1. **自动投掷：** 回旋刃装备且冷却完成时，优先向附近目标方向投掷；没有目标则沿玩家当前朝向投掷；**发射不造成瞬时近战伤害**。
2. **固定去程：** 回旋刃以 240 世界单位/秒飞行，投掷时锁定朝向，**沿朝向投影的前进距离必须达到 168 世界单位才折返**。较近目标被命中、击杀或移出地图均不能缩短飞出距离；侧向弧线只是改变视觉路径，不改变规定的前进距离。靠近边缘时自动寻找不穿越世界边界且与原朝向最接近的可行发射方向，不再通过贴边裁切悄悄缩短射程。
3. **折返：** 达到最大距离后切换为 `returning`，自动朝玩家**当前**位置移动，玩家移动后仍可回收；主人死亡或离房则清理投掷物。
4. **命中：** 服务端按**每个固定 Tick 的扫掠线段**与怪物圆形体积碰撞，避免高速穿透目标。去程、回程的命中集合分别计数，同一个敌人在每一程最多受击一次；回程伤害取本次投掷快照的 65%（四舍五入）。
5. **击退：** 有效命中后将怪物沿远离玩家的方向击退，使用原有 26 单位击退规则。其余生命、伤害统计、经验归属和死亡逻辑仍由既有 `DamageSystem.applyEnemyDamage` 负责。
6. **投掷限制：** 同一玩家场上同时最多存在一把回旋刃；冷却从发射时开始计算，且旧飞刃必须消失或收回才能再次发射。
7. **等级成长：** I 级基础伤害 22；II 级 +20% 伤害；III 级扩大去程弧线横向摆幅 25%。*旧版“瞬时扇形角度扩大 25%”不再适用。*
8. **视觉表现：** 客户端根据服务端投掷物的 ID、位置与 `outbound/returning` 状态创建持久旋转的双翼刀刃（Phaser Graphics），用 95ms 插值平滑 10Hz 网络快照；服务端到达精确最远点时发送 `weapon.returning` 事件，客户端显示折返光圈。保留简单发射闪光，取消旧版近战斩击动画。素材沿用已有免费资源与程序化轮廓，不生成 AI 图片。
9. **暂停与重开：** `UPGRADING` 阶段服务器暂停投掷物移动/伤害；进入下一局时清空所有投掷物和状态。客户端只播放表现，不能提交命中结果。

## 参数（当前原型）

| 参数 | 值 |
|---|---:|
| 基础伤害 | 22 |
| 攻击间隔 | 0.9 秒（18 Tick） |
| 固定去程距离（投掷方向投影） | 168 世界单位 |
| 去程/回程速度 | 240 世界单位/秒 |
| 投掷物碰撞半径 | 12 世界单位 |
| 去程伤害倍率 | 100% |
| 回程伤害倍率 | 65% |
| 击退 | 26 世界单位 |
| III 级弧线摆幅 | +25% |
| 每位玩家同时飞行数上限 | 1 |

**取舍：** 原先近战回旋刃的伤害并不能直接与新版双程命中等价。168 距离、回程 65%、摆幅系数属于首版手感参数，建议后续依据实际 4 分钟对局数据调整。

## 固定射程运行时验收（2026-10-11）

服务端原已使用 `outwardDistance=168` 折返，但原 360 单位/秒导致去程仅 0.47 秒，客户端 10Hz 位置快照和 95ms 插值很可能在视觉上错过最远点；若本地仍运行旧服务端，也会继续观察到旧行为。

- 飞行速度改为 **240 单位/秒**，仍固定飞 **168 单位**：每个 20Hz Tick 前进 12，**第 14 Tick / 0.7 秒** 才切换折返。
- 服务端于到达 168 时发出唯一 `weapon.returning` 事件，载明最远点坐标和距离；客户端在最远点显示紫白色短暂光圈，不由前端决定提前返回。
- 网络投掷物状态新增只读 `outwardDistance`、`maxDistance`，可证明当前服务器真实数据。
- 客户端页面添加参数 `?debugBlade=1`（如 `http://127.0.0.1:5173/?debugBlade=1`），显示 `OUT 0…168/168` 然后 `RETURN 168/168`。出现“旧服务端 Schema”说明运行进程没有加载新版服务端；如根本没有调试读数，应确认客户端 Vite 与 Git 提交。
- 近距离敌人、目标消失、无目标、贴近世界边缘、单次最远点事件与重新启动等测试均纳入回归。**浏览器可视手感仍需人工测试**。


## 注意

- 当前 16×16 临时素材分辨率有限，程序绘制的旋转刀刃主要保证**可辨认的投出与折返动作**，不代表最终美术质量。
- 实际部署时必须同时更新服务器和客户端（投掷物 Schema 已新增 `phase`）。
- 依旧不执行 F-09/F-10 或长期压力验收；浏览器飞行轨迹和手感仍需单人/双人实际试玩确认。
