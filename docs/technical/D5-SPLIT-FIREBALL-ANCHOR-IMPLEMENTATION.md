# D5 实现记录：裂变火球与空间锚点复核

> 工作分支：`codex/v2-dual-weapon-foundation`。设计依据：V2.2、V2.3、V2.5、V2.6。发布版本 v0.1.5。

## 本次正式实现
- 火焰弹 II 级由余烬火种和裂变火球两条可选择且互斥的分支构成，分别提供 III 级强化。旧版 legacy 的升级规则保持不变。
- 裂变主弹每次合法直接命中后产生两枚火星，III 级提升三枚。火星基础伤害为主弹的 35%，受固定整数舍入，带自身唯一服务器弹丸 ID、目标选择与有限寿命；它们不能再次分裂或对原始目标重复命中。若附近没有其他敌人，会沿扇形飞行直到命中其他合法目标或超时。
- 火星属于服务器计算的真实投射物，客户端只根据 10Hz 同步的 `split` 标志缩小视觉模型；不使用客户端命中决定伤害。
- 空间锚点保留 II 最多五发友方主火球重定向、III 最多八发且短暂四 Tick 绕行。裂变后的次生火星不再被空间锚点重新定向；无合法弹体时锚点仍有小牵引和约 40% 基础终结伤害。
- 服务端 V2 重抽候选资格检查使用当前世界的规则池，不再误用 legacy 升级选项。

## 明确未包含

- 多重引力的同敌人单 Tick 唯一来源、战斗事件优先级与 12 分钟正式平衡（后续独立阶段）。
- 真实多人设备的帧率和弹幕可读性尚需验收。

## 自动/人工验收
- 分支互斥、II 与 III 火星数量、火星不会再次分裂/不能重新击中原目标、独立火种仍可产生、空间锚点空场弱冲击、旧规则回归。
- 网页测试：两条火球分支分别选取并升级，直接命中产生 2 或 3 枚小火星；带空间锚点时普通火球只重定向一次，次生火星不发生无限折返。客户端若缓存老版本，强制刷新后观察 v0.1.5。
