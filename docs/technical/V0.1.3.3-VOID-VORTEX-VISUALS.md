# v0.1.3.3 黑洞旋涡美术重做

## 设计目标

将旧版“椭圆地面投影 + 几段静态轨道 + 同心圆”替换为向内吸积的动态奇点，参考暗黑奇幻俯视角美术。新版不应遮住敌人行动，也不能让玩家混淆真实的引力判定范围。

## 分层

1. **圆形引力暗场**：弱透明、圆形递减的暗层；移除原先横向拉伸的紫色椭圆投影。
2. **螺旋吸积流**：坍缩分支四臂紫色螺旋，空间锚点三臂青蓝螺旋，采用不同旋转方向与速度。
3. **断裂轨道**：四段不同半径、长度的轨道光弧，逆向缓慢绕行。
4. **吸入粒子**：十六个确定性碎片沿螺旋由外向内靠近中心，逐渐增亮，回绕循环，不依赖随机数。
5. **深黑核心**：内层纯黑，外层强紫色吸积环与不对称高亮新月，吸收火种变为橙色，残响增加辉光。
6. **结算阶段**：`collapsing` 在原有服务端阶段缩小至 0.62，`aftershock` 保留 0.88 的涡流残影；服务器事件继续决定最终冲击波特效。

## 性能及同步

- 沿用原 `createV2VoidCore` / `updateV2VoidCore` 签名与 `VoidFieldView`，只有客户端 Phaser Graphics 生成与更新发生变动。
- 动画计数在 `advanceAnimation=false` 时停止，手动升级期间不自行流逝。
- 每两次动画调用重新绘图一次；阶段、半径、残响或火种发生同步变化时立即绘制。
- 核心半径来自服务器 `view.radius`。画面上的轨道和粒子不参与伤害、位移、命中判定。
- 飞行阶段投射物表现暂时保留，实际飞行、吸附、坍缩、余震、双重祝福逻辑不改。

## 验收

- 单人进入双武器挑战，等待虚空法球落地：应看到中心纯黑、发光吸积环与动态向心碎片；不会出现扁长椭圆。
- 和火种互动后光环变暖色；空间锚点仍为青蓝色，玩家可区分两条进阶路线。
- 出现升级选择界面时涡流暂停，继续战斗后恢复；两名玩家同屏多枚核心时保持可读和帧率。
- 坍缩后由服务端事件显示冲击与伤害，视觉特效不得提前替服务端结束判定。
- 桌面与手机各确认黑洞保持圆形，不被 CSS 或摄像机拉伸。游戏主版本保持 `v0.1.3.3`。
