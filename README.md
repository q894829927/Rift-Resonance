# 异界共振（Rift Resonance）

> 像素角色 × 华丽技能特效 × 2～4 人多人合作弹幕 Roguelike

## 项目状态

- 当前阶段：**M0-C 固定 Tick 与响应式显示已实现，M0-D 玩家移动尚未开始**
- GDD 版本：**V1.0（待原型验证）**
- 战斗定位：**70% 割草 + 30% 弹幕躲避**
- 平台：**桌面浏览器优先**
- 部署目标：**阿里云 ECS 2 vCPU / 2 GiB / 40 GiB**

## 核心玩法

2～4 名玩家通过浏览器组队，在持续升级的怪潮中选择武器与被动强化。队友的冰冷、灼烧、闪电与猎杀标记可以触发「碎裂」「超载」「猎杀」等共振效果，合作挑战最终 Boss。

## 开发与验证

要求 Node.js 24 LTS 和 npm。首次安装及后续复现建议使用已经提交的 `package-lock.json`：

```bash
npm ci
npm run verify
npm run dev:server     # 终端 1：Colyseus 服务，默认 2567
npm run dev:client     # 终端 2：Phaser 占位页面
```

检查服务端健康接口：`http://127.0.0.1:2567/health`。

M0-B 已通过 GitHub Actions 的构建、领域单元测试、真实 SDK 联机集成测试、HTTP 烟测和生产依赖高危漏洞门禁。**已加入 20 Hz 固定 Tick、响应式画布和 HTML 原生文字，尚未实现角色移动与战斗。请在本地进行多分辨率视觉验收。**

房间操作：标签 A 点击「创建新房间」，复制房间 ID；标签 B 输入相同 ID 并点击「加入」，双方应显示两名玩家；退出后成员数量自动更新。

服务端运行期间还可以在第三个终端执行：

`npm run test:integration`

访问地址仍为 `http://127.0.0.1:5173`，服务端健康接口为 `http://127.0.0.1:2567/health`。

> GDD 数值待游戏原型测试。此阶段无战斗功能；公网开放前还需进行依赖安全审查、网络与合规配置。

## M0-C 本地验收

在浏览器创建房间后，画布上的标题使用 HTML 原生字体，不再被旧版固定 960×540 Canvas 位图放大；底部的 `Tick N` 应随服务器更新增长。调整窗口大小，角色的逻辑出生坐标不变，窄屏自动显示上下布局。详细步骤请查看 [M0-C 说明](docs/technical/M0-C-IMPLEMENTATION.md)。


### M0-C 显示清晰度修复

角色头顶/脚下昵称现由随世界坐标定位的 HTML/CSS 渲染，不再生成随 Canvas 放大的 Phaser 字体纹理。当前圆环与方块是矢量占位图形，已关闭全局 pixelArt 最近邻采样，避免圆弧锯齿。未来真正的像素素材再单独启用最近邻采样。请检查不同浏览器缩放和窗口宽度下昵称与角色是否对齐。
