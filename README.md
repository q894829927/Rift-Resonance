# 异界共振（Rift Resonance）

> 像素角色 × 华丽技能特效 × 2～4 人多人合作弹幕 Roguelike

## 项目状态

- 当前阶段：**设计完成，尚未开始游戏代码开发**
- GDD 版本：**V1.0（待原型验证）**
- 战斗定位：**70% 割草 + 30% 弹幕躲避**
- 平台：**桌面浏览器优先**
- 部署目标：**阿里云 ECS 2 vCPU / 2 GiB / 40 GiB**

## 核心玩法

2～4 名玩家通过浏览器组队，在持续升级的怪潮中选择武器与被动强化。队友的冰冷、灼烧、闪电与猎杀标记可以触发「碎裂」「超载」「猎杀」等共振效果，合作挑战最终 Boss。

## 计划

| 阶段 | 目标 |
| --- | --- |
| M0 | 技术验证：双人连接、输入和位置同步 |
| M1 | 基础战斗：移动、伤害、怪物、自动攻击 |
| M2 | 联机垂直切片：房间、经验、升级、首个共振 |
| M3 | 构筑：职业、武器、被动、进化与共振 |
| M4 | 内容闭环：地图、精英、Boss、12 分钟一局 |
| M5 | ECS 部署与联机、性能、流量测试 |
